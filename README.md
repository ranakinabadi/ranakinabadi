## Featured Projects

###  Multimodal Cancer Prognosis(`multimodal-cancer-prognosis`)
Deep learning framework integrating imaging and clinical data for cancer outcome prediction in NSCLC patients (TCIA dataset, n=200).  
**Tech:** PyTorch · MONAI · Survival Analysis

###  Topology-aware Segmentation (`topo-segmentation`)
Persistent homology applied to expose topological failure modes in Dice-trained segmentation models. A GNN trained on the resulting component graph achieves 94.3% node accuracy.  
**Tech:** PyTorch · Persistent Homology · Graph Neural Networks

###  Cell Morphology CVAE (`cell-morphology-cvae`)
Probabilistic 32-dimensional latent space structured by biological context — enables conditional generation, latent interpolation, and quantified morphological variation.  
**Tech:** PyTorch · Variational Inference · Conditional Generation

###  Capacitated Vehicle Routing Problem (CVRP)
MILP formulation and optimization using Julia/JuMP and HiGHS.  
**Tech:** Julia · JuMP · Operations Research
